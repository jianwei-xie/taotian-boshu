# 淘天播术-电商直播话术军师 - 直播话术智能分析系统

> 一个能帮中小商家多赚钱的工具。每一行代码都在回答：这个能帮商家多卖货吗？

## 系统简介

**淘天播术-电商直播话术军师**是一个专为淘宝直播商家设计的智能分析工具，帮助商家：

- ✅ 知道哪句话真的卖货，哪句话是废话
- ✅ 理解为什么别人的话术好用，自己的不好用
- ✅ 获得可直接执行的话术优化建议
- ✅ 零配置开箱即用，10分钟出结果

## 核心功能

### 1. 视频处理
- 自动语音转文字（支持中文）
- 智能话术分割（10-30秒一段，符合直播节奏）
- 自动过滤语气词（"嗯啊哦"等）

### 2. 话术分类
- 8大标签自动识别：产品介绍、价格福利、痛点共鸣、逼单催促、互动引导、信任背书、使用教程、售后承诺
- 零样本分类，无需商家标注
- 置信度低于0.6自动归到"其他"

### 3. DID归因分析
- 双重差分法排除自然流量干扰
- 7个时间窗口分析：0-1分钟、1-3分钟、3-5分钟、5-10分钟、10-20分钟、20分钟-1小时、1-2小时
- 精确计算每句话带来的增量GMV

### 4. 话术优化
- 基于历史数据推荐最优话术组合
- 分阶段建议：开场、中场、收尾
- 输出可直接执行的话术比例

## 配置说明

系统默认配置在 `config.py` 中，一般情况下无需修改：

```python

SEGMENT_MAX_DURATION = 30      # 最长30秒
```

## 注意事项

1. **数据安全**：系统不会保存商家的任何数据，分析完成后自动删除
2. **隐私保护**：所有处理都在本地完成，不会上传到云端
3. **模型选择**：默认使用规则分类器，如需更高准确率可启用BERT模型（需要GPU）

## 常见问题

**Q: 为什么不用BERT模型？**  
A: BERT模型需要下载大量参数，加载慢，且需要GPU才能达到理想速度。规则分类器虽然准确率略低，但速度快10倍，对商家来说"能跑通比什么都重要"。

**Q: 可以分析多长时间的直播？**  
A: 建议单次分析不超过3小时的直播。时间太长可以分段分析。

**Q: 订单数据需要什么格式？**  
A: 支持CSV和Excel格式，必须包含订单时间和金额列。系统会自动识别列名。

**Q: 分析结果准确吗？**  
A: DID归因方法可以排除自然流量干扰，得到话术的真实效果。但任何模型都有误差，建议结合商家自己的经验判断。
